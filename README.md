# MedTrack Pro

This application uses Google's Gemini GenAI to provide personalized medication tips and health insights.

## Prerequisites

Before running the application, you must provide your own Gemini API key.

1.  Open the `local.properties` file in the project root directory.
2.  Add the following line to the file:
    ```properties
    apiKey=YOUR_API_KEY_GOES_HERE
    ```
3.  Replace `YOUR_API_KEY_GOES_HERE` with your actual Gemini API key from [Google AI Studio](https://aistudio.google.com/).
